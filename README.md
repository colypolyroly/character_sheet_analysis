# character_sheet_analysis
Analysis of 1.2 million D&amp;D character sheets using SQL, Python, PostgreSQL, and Tableau. Exploring patterns in character creation, including class, level, ability scores, feats, and multiclassing, to uncover trends in how players build their characters.

# Dataset Download
You can download the data from this websit: https://www.kaggle.com/datasets/maximebonnin/dnd-characters-test
The top right corner has a download button.
